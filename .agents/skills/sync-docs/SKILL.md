# 日本語正本 → 英語ミラー

内容の修正は日本語側で行い、この同期処理は英語側だけを再生成する。
英語から日本語へ逆生成しない。

## 対象を選ぶ

- `*.ja.md` → `.ja` を外した同じパス（例: `README.ja.md` → `README.md`）。
- `docs/specs/ja/<name>.md` → `docs/specs/en/<name>.md`。
- `AGENTS.md` / `CLAUDE.md` は日本語のみでミラーを作らない。

指定ファイル/パスがあればそこに限定する。`all` または「全部」は追跡された全日本語
ソース、`--staged` は staged の日本語ソース、それ以外は staged・unstaged・untracked
の変更から対象を選ぶ。該当なしならその旨を報告して終了する。

## 翻訳と確認

協調機能が使える場合、Codex では `gpt-5.6-luna`、Claude Code では `sonnet` に
対象をまとめて委任する。現在の実行環境でホストを判定し、設定から推測しない。
指定モデルや委任機能が使えなければ現在のエージェントで続け、その制約を報告する。
親が対象選定と最終 diff 確認を担当し、翻訳担当には日本語ソース、既存ミラー、
以下の規則を渡して英語ミラーだけを編集させる。

- 見出し・順序・表・箇条書き・引用・コードなどの構造を保ち、散文だけ翻訳する。
- コード・識別子・パス・API ルート・コマンド・製品名を翻訳しない。
- リポジトリ内の文書リンクは対応する英語側へ張り替える。
- 設計・例・意見を追加せず、日本語側の追加と削除を忠実に反映する。
- ミラーの 1 行目に実際の日本語ソースパスで次のバナーを置く。

```text
<!-- AUTO-GENERATED from <ja-path>. Do not edit by hand — edit the Japanese source and run /sync-docs. -->
```

既存ミラーにバナーがなければ手編集の可能性をユーザーに伝え、差分を照合する。
同期依頼の範囲で再生成できる内容は進め、意図が判断できない独立変更を上書きしない。
使用した翻訳モデル、更新したミラー、スキップや未解決事項を簡潔に報告する。
